# Gestión del corpus V1

Registro de autoridad, versión, captura, vigencia conocida, derechos y revisión. Los snapshots, fuentes capturadas y sus recibos permanecen en el expediente local; derechos desconocidos no se convierten en permiso de distribución.

Esta es la documentación pública sanitizada. Los informes aplicados, resultados de operadores, paquetes privados y recibos completos se conservan localmente, fuera de Git. El checkout público permite comprobar los contratos y casos sintéticos; no reproduce por sí solo los expedientes históricos.

`tools.test_audit_corpus_reference_v1` es una suite de integración local: necesita el banco aceptado y las capturas privadas. No forma parte del gate portable de GitHub; su ausencia no se presenta como un PASS.
