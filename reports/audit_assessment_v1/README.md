# Valoración de hallazgos V1

Contrato común de hallazgo, explicación de cobertura no evaluable y método de prioridad/conclusión. La proyección de poblaciones está restringida a los casos revisados por su adaptador; no es ingestión universal. Sin destino, plazo y consecuencias verificadas, la prioridad permanece UNASSESSED.

Esta es la documentación pública sanitizada. Los informes aplicados, resultados de operadores, paquetes privados y recibos completos se conservan localmente, fuera de Git. El checkout público permite comprobar los contratos y casos sintéticos; no reproduce por sí solo los expedientes históricos.

Desde la raíz del repositorio, con Python 3.12:

```powershell
python -m unittest tools.test_audit_assessment_v1 -v
```
