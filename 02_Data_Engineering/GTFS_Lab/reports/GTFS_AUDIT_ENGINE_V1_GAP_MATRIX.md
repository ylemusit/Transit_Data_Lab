# GTFS Audit Engine V1 — Gap matrix (G01)

Baseline `4bb2275d9792942d5c879ca22d01fa250413457f`; normative baseline: official GTFS Schedule Reference revised 2026-04-27. This matrix is a design artifact, not an implementation or conformance result. Statuses describe capability support: `COMPLETE`, `PARTIAL`, `MISSING`, `OUT_OF_SCOPE_V1`.

| Capability | Official requirement | Current support | Current rule/code | Gap | Status | V1 disposition | Proposed implementation block |
|---|---|---|---|---|---|---|---|
| ZIP, file names, CSV structure | root-level files, case-sensitive names, delimited text, valid CSV/header | Partial: safe ZIP/CSV checks; fixed catalog and nested-file warning | `ingestion.py` | No complete official catalog or unknown-feature coverage; locations GeoJSON unsupported | PARTIAL | V1_REQUIRED | G02, G03 |
| Required file presence | agency/routes/trips/stop_times required; stops conditional on zones | Partial; stops universally required | `GTFS-STRUCT-REQUIRED`, `ingestion.REQUIRED` | False failure for valid Flex shape; unknown files not represented | PARTIAL | V1_REQUIRED | G03 |
| Calendar file condition | calendar or calendar_dates conditions; dates-only enumerates all service dates | Partial presence only | `GTFS-STRUCT-SERVICE-CALENDAR`, `analysis._service_calendar` | Does not prove complete dates-only coverage or service resolution | PARTIAL | V1_REQUIRED | G03, G05 |
| Core schemas and field presence | Required fields and conditional/forbidden fields per reference | Partial for five files, required-column subset | `ingestion.REQUIRED_COLUMNS` | No full schema/type/conditional field evaluation | PARTIAL | V1_REQUIRED | G03 |
| Core IDs and primary keys | file primary keys; unique IDs; correct composite keys | Partial, four columns only | `GTFS-UNIQUE-PRIMARY-ID` | Missing composite keys, empty/duplicate semantics and most files | PARTIAL | V1_REQUIRED | G04 |
